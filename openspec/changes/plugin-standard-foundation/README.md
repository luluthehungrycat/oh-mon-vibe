# plugin-standard-foundation

Define and validate the prerequisites for a future cross-harness plugin
standard and standalone SDK without prematurely promising interoperability or
isolation.

Artifacts:

- `design.md` — contract and migration decisions.
- `adapter-mappings.md` — Hermes Agent and OpenCode conceptual mappings.
- `conformance-fixtures.md` — host and adapter fixture matrix.
- `review.md` — internal contract review and readiness decision.
- `review-request.md` — owner review questions and required response.

SDK implementation remains blocked until the owner review is complete.
